How every number on the dashboard is calculated and how it affects the result. Only the four bold KPIs have targets; they pick the best-fit option.

10-20-30 rule (Santamour 1990)Largest share of one species, one genus and one family among the new trees. Each tree gets the least-used species that fits its soil and moisture and stays within the limits; if its size class has no such species left, it changes class (smaller first, larger only where spacing allows)≤ 10% species, ≤ 20% genus, ≤ 30% family [3]Met for every option and budget tested (20–200 trees). Synergy indexTeam's ecosystem score, 0–100 = average of four parts. Habitat: canopy vs 30%, crown over open ground, unsealed share vs 50%. Diversity: Shannon, native share, wildlife (assumed 0.5), halved if 10-20-30 is broken. Connectivity: 1 − longest gap ÷ 100 m, plus reaching the Dommel.
